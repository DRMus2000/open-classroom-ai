## 复验摘要

- 便携 Python 3.11.9：56 项测试通过；其中 30 人文件 SQLite 队列完成 30 次唯一派发，峰值并发 4，每人 used=1/reserved=0。
- Open WebUI 0.11.2 实际模块、认证、文件、函数、模型权限、聊天和原生数据库：`NATIVE_AUTH_FILE_CHAT_CONTRACT_OK`。测试中的提供商为模拟。
- 新数据库中文空格目录：Start/Bootstrap/Status/重复 Start/Stop 全流程通过，测试实例已停止。
- 迁移：2 user、2 auth、4 chat、18 chat_message、0 file、6 legacy_review，原生结构哈希与逐表内容摘要写入演练报告。
- 受保护回滚：先生成切换后备份，再将之前备份恢复到新目录，两个备份与原目录保留。
- 有附件的原生迁移：`NATIVE_LEGACY_FILE_MIGRATION_EXPORT_OK`，真实文件路由创建的 Python 文件在迁移后教师 ZIP 中完整保留。
- JavaScript 三份文件语法检查、PowerShell 全部脚本解析通过。
- 浏览器合成教师登录、管理页加载、暂停/恢复实际通过。首次解压验收发现逐请求建立 HTTP 客户端使桥接约耗时 2.7 秒；改用共享客户端并在生命周期退出时关闭，新增连接复用回归。5 次带身份验证管理接口实测 28.8 / 22.9 / 23.2 / 24.3 / 14.9 毫秒。原生 OpenAI/Ollama/arena 模型发现也在课堂模式关闭。

## 验收边界

这些结果关闭了原报告的代码整改工作，但不等于已经完成学校现场验收，也不将原 475 项检查表自动改成全 PASS。真实提供商响应差异、30 台学生浏览器、校园网断连/延迟、全新 Windows 主机、防火墙和教师实际操作仍按原计划 K/L 执行。现有源库没有旧附件，有附件迁移已另用原生路由创建的合成文件演练。

当前原安装保持原样。使用新包前按教师指南初始化或迁移到新目录。
