## 2. 缺陷清单（按修复顺序）

### C01 — Critical — Git 跟踪秘密与运行时数据

- **位置：** 索引/历史中的 `private-data-backup-*/`、`rehearsal/**`、`release/openwebui-classroom-windows-x64/**`、各类 `__pycache__`；至少 67 条密钥/数据库路径仍被 `git ls-files` 列出。
- **证据：** 工作树已删文件，但索引仍引用 `bridge.key`、`.webui_secret_key`、`classroom.db`、`webui.db` 等；`release/` 曾跟踪约 4 万文件的完整运行时。
- **影响：** 任何拿到仓库副本的人可读历史中的签名密钥、会话材料、账号库。
- **修复：** 扩展 `.gitignore`；`git rm --cached` 停止跟踪上述树与 `release/*.zip`；保留源码与文档；提示轮换密钥。不重写历史（除非明确要求）。
- **提交：** `chore(security): stop tracking secrets, rehearsal data, and release artifacts`

### H01 — High — 已认证 WebSocket / `/ws/*` 绕过 HTTP 白名单

- **位置：** `app/openwebui_bridge/middleware.py` 约 92–98 行。
- **证据：** 会话校验后，`websocket` 或 `/ws/` 仅做帧级 `identity/validate`，不套用学生 `allowed` 列表，也不强制 Pipe。
- **影响：** 若原生 Socket.IO/事件可触发生成或其他特权动作，学生可绕过 HTTP 侧课堂出口与额度。
- **修复：** 学生对 WebSocket 默认拒绝；教师/admin 可保留带重校验的 WS（供管理 UI）。补回归测试。
- **提交：** `fix(security): deny student WebSocket access by default`

### H02 — High — 教师/admin 跳过学生出口拒绝列表

- **位置：** `middleware.py` 约 67–68 行；`tests/test_bridge_security.py` 明确期望教师访问 `/api/embeddings` 返回 200。
- **证据：** `user.role == 'admin'` 时除聊天 POST 外直接 `return await self.app(...)`，可走 `/openai/`、`/ollama/`、embeddings 等。
- **影响：** 教师会话可在课堂额度/审批/审计之外调用原生模型出口（与「唯一课堂出口」目标冲突）。
- **修复：** 对 admin 也拒绝原生模型出口前缀；教师对话继续走 `/api/classroom/v1/admin/chat/completions` 与 Pipe 清洗路径。更新测试。
- **提交：** `fix(security): keep teacher model egress on classroom routes only`

### H03 — High — Open WebUI 默认绑定全网卡且无 TLS

- **位置：** `scripts/Start.ps1` 参数 `BindHost = '0.0.0.0'`。
- **证据：** 课堂服务正确绑 `127.0.0.1`；WebUI 默认监听全接口，脚本提示 `http://<teacher-ip>`。
- **影响：** 校园网内会话 Cookie/Bearer 与聊天明文可达教师机。
- **修复：** 默认 `127.0.0.1`；增加显式 `-Lan`（或等价开关）才绑定 `0.0.0.0`，并打印明文风险提示。
- **提交：** `fix(startup): default WebUI bind to loopback unless LAN mode is explicit`

### M01 — Medium — Cookie 认证写请求在缺少 Origin 时不校验

- **位置：** `middleware.py` 33–35 行。
- **修复：** Cookie 会话的变更请求要求 Origin 与 Host 一致；仅 Bearer 可放宽。  
- **提交：** `fix(security): require Origin for cookie-authenticated mutating requests`
